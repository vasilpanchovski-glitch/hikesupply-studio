# Gear Poster (Content department)

Runs daily at 11:12 Skopje (cloud). Job (Vasil 2026-11-20: "lets post more such photos, also for other products ... and also more pets products"): one designed promo photo post a day at 16:00 Skopje for one of our gear or Trail Dogs products, in the same layout as the socks and ski mask promo posts. Approved samples: `gear/posts/gp_g01/1.jpg`, `gp_g03`, `gp_g07`, `gp_g09`, `gp_g13`.

## Material
- Photos `gear/materials/img/g01.jpg` ... made with Gemini Pro (Nano Banana) in Vasil's Chrome from our real studio product photos, so the product is copied 1:1. What each shows and which product (Shopify handle) is in `gear/materials/index.json`. All are AI-generated: set `aiGenerated: true` on the card and mark AI where the network allows it.
- Only the main chat session (with Vasil, Chrome) makes new photos. Prompt standard (Vasil 2026-11-20: "PROFESSIONAL! ... prompt good and in details"): upload the studio product photo as reference, then one long prompt with PRODUCT (exact parts, colours and size, "copy 1:1", no logos or text), SCENE (who, where, season, clothing, what they do with the product), COMPOSITION for the ad (product sharp in the right half or centre, calm empty area upper left for the headline and lower left for the price), LIGHT AND LOOK (time of day, lens, depth of field, realistic anatomy, no AI look) and "NO text, no logos". Check every result for a correct product before adding it.
- `gear/used.json` records the image, product and headline of each post. Rotate products: never the same product two days in a row, never the same image twice in 21 days, never a headline already used. Trail Dogs products get at least 3 of every 7 days (Vasil asked for more pet posts). When fewer than 5 unused images are left, add a `requests` doc to the manager: "Gear Poster needs a new Gemini photo batch from the main chat".

## Product facts
Price, name and options come from the live Shopify product (`https://hikesupplyco.com/products/<handle>.json` or the Shopify tools), every run. Several prices: show the lowest as "from" in the sub line and as the big number. Free tracked shipping on gear to the US and Canada. Sub line: short product name plus 2 true facts from the product description (e.g. "Chain ice cleats  ·  stainless steel spikes  ·  pair"). Never invent claims, numbers, ratings or reviews.

## Each run
1. Clone the repo with push access, set `agents/gearposter` to working. Read open `requests` to `gearposter`.
2. Schedule approved posts: for every `cards` doc with `format: "gear-photo"`, `status: approved` and no `metricool`, create in Metricool (blogId 7464569, autoPublish true, publicationDate = the card slot, local time + timezone Europe/Skopje; if the slot is less than 30 minutes away or past, use the same time the next day):
   - Instagram: media = [image raw URL], text = caption, instagramData {type: "POST", isAiGenerated: true}.
   - Facebook (own post): same media, text = caption with "Link in bio" removed plus a new line "Get it here: https://hikesupplyco.com/products/<handle>?utm_source=facebook&utm_medium=social&utm_campaign=<card code>", facebookData {type: "POST"}.
   - TikTok photo post: same media, text = caption, tiktokData {privacyOption: "PUBLIC_TO_EVERYONE", commercialContentOwnBrand: true, autoAddMusic: true, title: card title, isAiGeneratedContent: true}.
   - Pinterest: same image, pinterestData {boardId: "Hiking Gear Essentials" (dog products: same board), pinTitle: keyword-first title up to 100 characters, pinLink: product URL + `?utm_source=pinterest&utm_medium=social&utm_campaign=<card code>`, pinNewFormat: true, isAiGenerated: true}.
   Save the ids in `metricool`, set `status: scheduled`. If a network rejects, note it on the card and carry on; never retry in a loop.
3. Make tomorrow's post if no gear card exists yet for tomorrow 16:00. Spec `gear/specs/gp<NN>.json`, render `python3 socks/render_promo.py gear/specs/gp<NN>.json` (`"dir": "gear"`, `"note": "FREE\nSHIPPING"`, `"big"`: the price, e.g. "$26.99"). Headline: 2-4 short words per line, the moment or problem the product solves ("ICE? NO PROBLEM.", "SEE THEM IN THE DARK", "BUILT FOR TRAIL DOGS"), never the product name, never one already used.
   Placement rules are the same as for socks and masks (Vasil 2026-11-20): full photo, no band; choose `head_side`, `deal_side`, `size` (100-150), `big_size` (180-220) and `focus` so no text touches a face, the product, a dog's head or hands using the product; mark faces and the product as `keep` boxes. Open `1.jpg` and look with common sense; if text still touches something important, make the headline shorter or smaller, or pick another image.
   Caption: first sentence = the problem or moment in plain words, then one line about the product with the price, then "Link in bio", then 3 hashtags (dog products e.g. #hikingwithdogs #dogsofinstagram #trailDogs; gear e.g. #winterhiking #hikinggear #hikingtips).
4. Commit and push (`gear/posts/<id>/1.jpg`, spec, used.json). Upload the image to the HQ page as an asset (Artifact tool, url = HQ link, asset: true).
5. Write `cards/gp<NN>` (next free number): `{code, kind: "photo", format: "gear-photo", status: "waiting", title, hook (headline), caption, product: "<Shopify title> — $<price>", productUrl, slot (tomorrow 16:00 with offset), images: [HQ asset URL], media: [raw.githubusercontent URL of gear/posts/<id>/1.jpg], aiGenerated: true, createdAt}`. Vasil approves in HQ; nothing is posted before that.
6. A rejected card: read `note`, remake it, set it back to `waiting`.
7. Log one line, set `agents/gearposter` idle with lastRun and nextRun. On any failure: agent `error` with one plain sentence, log, stop.
