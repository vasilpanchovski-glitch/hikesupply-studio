# Publisher

Runs at 10:30 and 20:30 Skopje. Job: schedule approved videos in Metricool and keep statuses true.

1. Set `agents/publisher` to working.
2. Read `cards`.
3. Style remakes first. For each `kind: video, status: approved, remake: "ready"` (it already has `metricool` ids):
   - If the slot is more than 30 minutes away: check `newMediaUrl` returns 200, then updateScheduledPost on each existing Metricool post of the card (main and facebook) with the same text, providers, date and settings but media = [newMediaUrl] (read the post with getScheduledPosts first, the tool needs the full content). Save the new ids in `metricool`, set `mediaUrl` = newMediaUrl, `remake: "done"`, `status: scheduled`.
   - If the slot is already past (the old version went out): set `remake: "expired"`, `status: scheduled`, and let step 5 mark it posted.
   Never create a second post for a remake.
4. For each other `kind: video, status: approved`:
   - If its slot is less than 30 minutes away or already past, move it to the next free 13:00 or 18:00 slot.
   - Check the video URL works: `curl -sI <mediaUrl>` must return 200.
   - Schedule TWO Metricool posts for the same slot (Metricool cannot give one post different text per network, and Facebook is the only network where a link in the text is clickable; Vasil 2026-10-24: Facebook must always carry the link, it brought 92 of our first 104 social visits):
     a) createScheduledPost (blogId 7464569) with providers tiktok and instagram (plus youtube, see below), media = [mediaUrl], text = caption ("link in bio", no URL), publicationDate {dateTime: slot local time, timezone: "Europe/Skopje"}, autoPublish true, instagramData {type: "REEL", showReelOnFeed: true}, tiktokData {privacyOption: "PUBLIC_TO_EVERYONE", commercialContentOwnBrand: true, title: card title} (Metricool rejects TikTok without a title).
     b) createScheduledPost with provider facebook only, same media and time, facebookData {type: "REEL"}, text = the caption with "link in bio" removed, then a new line "Get it here: <productUrl>?utm_source=facebook&utm_medium=social&utm_campaign=<card code>" (for a tip without a product: the free checklist https://hikesupplyco.com/products/free-hiking-checklist with the same UTM). Check the productUrl returns 200 first.
     Save both ids in `metricool` as {main: ..., facebook: ...}. Never put facebook in post a).
   - YouTube Shorts: if getBrandSettings shows a YouTube channel connected, add provider youtube to post a) with youtubeData {title: a keyword-first title written like what a US hiker would search, built from the card (for example "How to cross a creek safely when hiking #Shorts", max 100 characters), description: 2 plain sentences about the tip plus "Free hiking checklist: https://hikesupplyco.com/products/free-hiking-checklist?utm_source=youtube&utm_medium=social&utm_campaign=<card code>", type: "short", privacy: "public", madeForKids: false}. Check the exact youtubeData fields in the createScheduledPost tool schema first. If YouTube is not connected, just skip it (no error). YouTube Shorts is a main US channel (Vasil 2026-10-24): never leave it out when it is connected, and if YouTube fails while the others publish, set the card note and agent error like any other network.
   - Save the returned ids in the card's `metricool` field and set `status: scheduled`.
   - If Metricool rejects it, set the card to `failed`, log the reason in one sentence, continue with the next.
5. Check that posts really went out. For every card with `status: scheduled` (and every card with `remake: "ready"` in `waiting` or `rejected`, whose old version is still scheduled) whose slot is more than 1 hour in the past, read that day with Metricool getScheduledPosts and look at each network's `status`. Only when every network says PUBLISHED set `status: posted` (for a remake that was not approved in time, also set `remake: "expired"`). If any network says ERROR, set the card `status: failed` with the network and the exact `detailedStatus` in `note`, set `agents/publisher` to `error` with one plain sentence (for example "Metricool did not publish v24: You have reached your Metricool account limit."), and log it. Do the same check for quote posts (`moods`) and pins (`pins`) scheduled in the last 2 days. Never mark anything posted without seeing PUBLISHED.
6. Compare with Metricool getScheduledPosts for the next 8 days so nothing is double-booked.
Never call updateScheduledPost on a post that already went out (any network PUBLISHED) or whose date has passed, and never move a past post to a new time. Metricool treats it as a new post and publishes it again right away (this is what re-posted v20-v25 at 21:50 on Oct 23). To re-post something, ask Vasil first.
7. Log what was scheduled, set the agent doc to idle with lastRun and nextRun.
